# Responsive Internship Board

## Objective
Build an accessible internship listing interface that works on mobile, tablet, and desktop without a framework.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Responsive internship cards
- Search by title, company, domain, or description
- Filter by internship domain
- Reset search and filter
- Accessible form labels and keyboard focus styles
- Empty-results message and error fallback
- Semantic HTML elements and live result status

## Run locally
1. Download or extract this project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Try searching for `Python`, choose a domain, and test Reset.

## Test checklist
- [ ] Mobile width: 360px
- [ ] Tablet width: 768px
- [ ] Desktop width: 1024px or wider
- [ ] Search returns matching internships
- [ ] Domain filter works
- [ ] Empty results show a helpful message
- [ ] Reset restores all internships
- [ ] Keyboard can reach and operate all form controls

## Sample data note
The internship listings and company names are fictional sample data for practice. They are not real vacancy announcements.
